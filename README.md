# 積立投資 & 定額取崩シミュレーション

`investment_sim`（積立投資シミュレーション）と `Withdrawal`（定額取崩シミュレーション）を1つのページに統合したツールです。見た目は `Withdrawal` のライトテーマに統一し、積立投資フェーズの**最終残高**が、そのまま定額取崩フェーズの**元本**として自動的に引き継がれます。HTML / CSS / JavaScript のみで構築されており、ビルドや依存パッケージは不要です。

## 特徴

- **① 積立投資フェーズ**: 元本・積立額（月額）・年利率・運用期間をスライダーで調整すると、最終残高・総投資額・運用益と資産推移グラフがリアルタイムに更新されます。
- **連携トグル**: 2つのフェーズの間にある「積立の最終残高を、取崩シミュレーションの元本として使う」スイッチで自動連携のON/OFFを切り替えられます。
  - **ON（デフォルト）**: フェーズ1の最終残高が、フェーズ2の元本として自動反映されます。フェーズ2の元本スライダーは無効化され、「連携中」の表示が出ます。
  - **OFF**: フェーズ2の元本スライダーが有効になり、フェーズ1とは独立した任意の元本で取崩シミュレーションを試せます。
- **② 定額取崩フェーズ**: 元本（連携時は自動入力）・年利率・毎月の取崩額をスライダーで調整すると、最終残高・資産が尽きる時期・資産推移グラフがリアルタイムに更新されます。

## 使い方

`index.html` をブラウザで開くだけで利用できます。サーバーの起動やビルド作業は不要です。

```
index.html をダブルクリック、またはブラウザにドラッグ＆ドロップ
```

## 計算ロジック

### 積立投資フェーズ

毎月、以下の複利計算を運用期間（月数）分繰り返します。

```
残高 = 残高 × (1 + 年利率 / 100 / 12) + 月額積立額
```

- 総投資額 = 元本 + 積立額 × 積立月数
- 運用益 = 最終残高 − 総投資額

### 定額取崩フェーズ（40年間固定）

- 月利 = 年利率 ÷ 12
- 翌月の残高 = 残高 + 残高 × 月利 − 毎月の取崩額（一定額）
- 残高が0以下になった場合は0として以降計算を継続し、最初に0になった月を「資産が尽きる時期」として記録する
- 40年（480ヶ月）以内に枯渇しなければ「40年以内に枯渇なし」と表示する

### フェーズ間の連携

連携ONのとき、定額取崩フェーズの元本には積立投資フェーズの `finalBalance`（最終残高）がそのまま使われます。積立側の入力値が変わるたびに、連携中であれば取崩側の計算・グラフも自動で再計算されます。

詳細は [script.js](script.js) の `getProjection` / `buildWithdrawalSeries` / `setLinked` を参照してください。
